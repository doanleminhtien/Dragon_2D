## 📖 Giới Thiệu (Overview)

**Dragon 2D** là một dự án game 2D thuộc thể loại Action Platformer được phát triển trên nền tảng **Unity Engine**. Trò chơi mang đến trải nghiệm điều khiển linh hoạt, đồ họa 2D sinh động và được tối ưu hóa mượt mà để chơi trực tiếp trên trình duyệt web.

👉 **🎮 CLICK ĐỂ CHƠI GAME TRÊN ITCH.IO: (https://minhtien2905.itch.io/dragon-2d)



## ✨ Tính Năng Nổi Bật (Features)

* ⚔️ **Cơ chế điều khiển mượt mà:** Hệ thống di chuyển, nhảy, va chạm (Physics 2D) được lập trình và tối ưu hóa tốt.
* 🎨 **Đồ họa & Animation:** Thiết kế sprite 2D sống động với đầy đủ trạng thái nhân vật (Idle, Run, Jump, Attack).
* 🔊 **Âm thanh chân thực:** Tích hợp Audio Manager cho nhạc nền (BGM) và hiệu ứng hành động (SFX).
* 🌐 **Tối ưu WebGL:** Tỉ lệ khung hình chuẩn 16:9, trải nghiệm trực tiếp trên trình duyệt mà không cần tải về.
